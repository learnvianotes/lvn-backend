# @lvn/contracts 0.2.0 — permission decisions and join requests

- Date: 2026-10-08
- Package: `@lvn/contracts` 0.1.0 → 0.2.0 (unpublished; pre-1.0, so a breaking change bumps the minor)
- ADRs: 0005 (accepted), 0009
- Breaking: **yes**, for code using the removed actions

## What changed

| Area | Change |
| --- | --- |
| `Action` | Removed `GROUP_JOIN` and `CLASSROOM_JOIN`. Added `GROUP_REQUEST_JOIN`, `GROUP_REVIEW_JOIN_REQUESTS`, `CLASSROOM_REQUEST_JOIN`, `CLASSROOM_ACCEPT_INVITE`, `CLASSROOM_REVIEW_JOIN_REQUESTS`. |
| `Resource` | `group` gains `pendingJoinRequest`; `classroom` gains `pendingJoinRequest` and `invitedByStaff`. |
| `can()` | Owners may fork their own PRIVATE notes; share Editors edit drafts of PUBLIC notes too. Join actions follow ADR-0009. |
| Enums | `JoinRequestStatus` (`PENDING`, `APPROVED`, `REJECTED`, `WITHDRAWN`). |
| Events | `GroupJoinRequested`, `ClassroomJoinRequested`, `JoinRequestReviewed` (version 1). |

## Authorization

Requests: verified non-members without a pending request (groups); non-members without a pending request
(classrooms). Review: group Admin/Owner; classroom Teacher/TA. Invite acceptance: the invited non-member.

## Migration

No consumers yet (web and mobile have no group or classroom screens). Replace `GROUP_JOIN` with `GROUP_REQUEST_JOIN`
and `CLASSROOM_JOIN` with `CLASSROOM_REQUEST_JOIN` or `CLASSROOM_ACCEPT_INVITE`.
