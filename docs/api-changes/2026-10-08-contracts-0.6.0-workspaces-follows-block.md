# @lvn/contracts 0.6.0 — project workspaces, student follows, block and restrict

- Date: 2026-10-08
- Package: `@lvn/contracts` 0.5.0 → 0.6.0 (unpublished)
- ADRs: 0015, 0016
- Breaking: no for callers; `GroupRole` gains `MENTOR`, so exhaustive `switch`es and `Record<GroupRole, …>` need it

## What changed

| Area | Change |
| --- | --- |
| Enums | `GroupRole.MENTOR`; `GroupType` (`COMMUNITY`, `PROJECT`); `GroupPostKind` (`POST`, `IDEA`); `DoubtStatus` (`OPEN`, `ANSWERED`, `RESOLVED`). |
| `Action` | `GROUP_INVITE_MENTOR`, `GROUP_ACCEPT_MENTOR_INVITE`, `GROUP_ASK_DOUBT`, `GROUP_ANSWER_DOUBT`, `GROUP_RESOLVE_DOUBT`, `USER_REMOVE_FOLLOWER`, `USER_BLOCK`, `USER_UNBLOCK`, `USER_RESTRICT`, `USER_UNRESTRICT`. |
| `Resource` | `group`: `type`, `mentorInvitePending`, `inviteeGlobalRole`, `isDoubtAuthor`. `user`: `targetRestrictedMinor`, `followsActor`, `blockedByActor`, `restrictedByActor`. |
| `can()` | Students follow students (never restricted minors); teachers still do not follow students. Mentors moderate posts and reports in their workspace. `NOTE_CREATE` allows `PROJECT` to anyone. |
| Events | `UserBlocked`, `UserUnblocked`, `UserRestricted`, `UserUnrestricted`, `MentorInvited`, `DoubtAsked`, `DoubtAnswered`, `DoubtResolved`. |

## Migration

None.
