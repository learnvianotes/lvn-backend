# @lvn/contracts 0.16.0 — moderation (Phase 2, P2d-1)

- Date: 2026-10-09
- Package: `@lvn/contracts` 0.15.0 → 0.16.0 (unpublished)
- Spec: §15.1; ADR-0037
- Breaking: `ModerationActionType` values are now upper case (`HIDE`, not `hide`) and gain `APPROVE`. Nothing used the
  old values.

## What and why

Public notes need a human in the loop before the first one ships (§15.1). Notes going public are screened, people can
report notes and accounts, and platform admins work through a queue until the admin app exists.

## `@lvn/contracts`

| Export | Change |
| --- | --- |
| `Action.CONTENT_MODERATE` | New: the platform moderation queue; PLATFORM_ADMIN only |
| `ReportEntityType` | New: `NOTE`, `USER` |
| `ModerationActionType` | `APPROVE`, `HIDE`, `REMOVE`, `WARN`, `SUSPEND`, `DISMISS` |
| API config `MODERATION_WORDS_FILE` | New, optional: extra `REASON: phrase` lines for the scorer |

## GraphQL

Notes subgraph: `Note.moderation: NoteModeration { state, reason, canAppeal }` — the owner's only (null for anyone
else). `ModerationState`: `OK`, `PENDING_REVIEW` (held from the public path; the people it is shared with still read
it), `HIDDEN` and `REMOVED` (the owner's alone).

Core subgraph:

| Field | Who | What |
| --- | --- | --- |
| `reportContent(input: { entityType, entityId, reason, details })` | signed in | Notes the reporter can read (NOT_FOUND otherwise, never their own) and other accounts. Reporting again updates the report. 20 an hour. Three open reports from different people hold a public note |
| `moderationQueue(first, after)` | PLATFORM_ADMIN | Open cases, oldest first: `ModerationCase { entityType, entityId, note: ModeratedNote, user, reports, appeal, openedAt }`; a report with `reporter: null` comes from the scorer |
| `moderateContent(input: { entityType, entityId, action, reason })` | PLATFORM_ADMIN | `APPROVE` frees a note, `HIDE`/`REMOVE` take it off, `DISMISS` closes reports and frees a held note, `WARN` the same with a message. `reason` is required for HIDE, REMOVE and WARN (the author sees it). Accounts: WARN and DISMISS only; SUSPEND is not available yet |
| `appealModeration(input: { entityType: NOTE, entityId, message })` | the note's owner | Once, for a hidden or removed note; reopens the case |

Behaviour changes: `changeNoteVisibility` to PUBLIC and `publishNote` on a PUBLIC note screen the published version and
may leave the note held (the payload's `note.moderation` says so); a hidden or removed note cannot be made PUBLIC
(FORBIDDEN). `NotePublished`/`NoteUnpublished` follow what the public can read.

## Data

`notes.Note.moderation`, `moderationReason`; `core.Report`, `core.ModerationAction`, `core.ModerationAppeal`; migration
`20261009030000_moderation`. Decisions are audited as `moderation.<action>`; holds as `moderation.held`.
