# AI tasks on notes (P5b)

- Date: 2026-10-13
- Package: `@lvn/contracts` 0.34.0
- Spec: §10.1, §10.3; ADR-0025, ADR-0059
- Breaking: no

## What changes for clients

- **`runAiTask(input: { noteId, task, language?, cardIds? })`** returns `{ artifact, userErrors }`.
  - `task` is an `AiTask`. Text results: SUMMARIZE, KEY_CONCEPTS, EXPLAIN_SIMPLY, PRACTICE_QUESTIONS, TRANSLATE,
    FIND_MISTAKES, EXPLAIN_CODE. Card results: FLASHCARDS, QUIZ, REVISION_SHEET, CREATE_NOTES, OUTLINE_TO_NOTE.
  - `language` (`AiLanguage`: ENGLISH by default, HINDI, TELUGU) is the language of the result. TRANSLATE translates
    into it.
  - Payload errors: VALIDATION (nothing to read, or no code for EXPLAIN_CODE), NOT_FOUND (cannot read the note),
    RATE_LIMITED (the day's allowance), UNAVAILABLE (AI off or failing).
  - FORBIDDEN is a GraphQL error: CREATE_NOTES or OUTLINE_TO_NOTE on a note whose owner does not allow copies.
- **`aiArtifact(id)`** returns an `AiArtifact` or null:
  - `status`: QUEUED, RUNNING, READY or FAILED;
  - text tasks: `markdown`; card tasks: `title` and `cards: [AiCard { type, content }]`;
  - `error` (FAILED), `fromPublishedVersion`, `truncated`, `keptAt`, `createdAt`, `note`.

  Poll it about every 1.5 s until READY or FAILED.
- **`Note.aiArtifacts`**: the viewer's own results for the note, newest first; empty signed out.
- **`keepAiCards(input: { artifactId, cardIndexes, into: NOTE | NEW_NOTE })`** returns `{ noteId, userErrors }`.
  NOTE is for people who can edit the note; for anyone else it is FORBIDDEN. CREATE_NOTES and OUTLINE_TO_NOTE results
  are always kept as a NEW_NOTE (VALIDATION otherwise).
- **`deleteAiArtifact(id)`** returns `OkPayload`.
- **`ErrorCode`** in every subgraph lists `UNAVAILABLE`.

## Authorization

- Every task needs read access to the note (Ask-AI); CREATE_NOTES and OUTLINE_TO_NOTE need the fork right.
- Results are visible only to their maker, while they can read the note.

## What clients should do

- Offer the AI menu on notes when `aiStatus.available`.
- Show results beside the note: Markdown for text tasks, card previews with checkboxes for card tasks. "Add to this
  note" appears only when `viewerCan.edit`; "Save as my note" always.
- Show `myAiAllowance`.
