# Weekly contests and the mock-interview data model (P8c, P8d)

- Date: 2026-10-14
- Package: `@lvn/contracts` 0.55.0
- Spec: ADR-0082, ADR-0083
- Breaking: no

## What changes for clients

- **`contests`**: published contests, for guests too. Open ones come first, then upcoming ones, then those closed in
  the last four weeks.
  - Each has `title`, `subjectTitle`, `opensAt`, `closesAt`, `minutes`, `questionCount` and `state` (`UPCOMING`,
    `OPEN` or `CLOSED`).
  - `participantsMilestone` is 1,000+, 2,000+… and null below the first.
  - `viewerAttempt` is the viewer's attempt, if any. **`contest(id)`** returns one contest.
- **`ContestAttempt`** has:
  - `startedAt`, `deadline`, `submittedAt`, `finished`, `score` (once finished) and `total`;
  - `questions`, in the viewer's order, each with its choices in the viewer's order and `myChoiceId`.
    `correctChoiceId` and `explanation` are null until the attempt is finished;
  - `personalBest`: the best share right (0–100) on the subject's contests, once finished;
  - `band` (`TOP_10`, `TOP_25` or `TOP_50`): only for an adult who turned bands on, once the window has closed, and
    computed among adults only.
- **`startContest(input: { contestId })`**:
  - one attempt each, while the contest is open. These are user errors: "It has not opened yet." and "It has closed.";
  - starting again returns the same attempt;
  - the server draws `questionCount` questions and orders each one's choices. The deadline is the earlier of the start
    plus `minutes`, and `closesAt`.
- **`answerContestQuestion(input: { attemptId, questionId, choiceId })`**: may change an answer until the deadline or
  submission. These are user errors:
  - "Your time is up: the attempt is marked as it stands.";
  - "That question is not in your attempt.";
  - "That is not one of its choices.".
- **`submitContest(input: { attemptId })`** marks the attempt. An attempt past its deadline is marked when it is next
  read.
- **`contestSettings`** returns `{ showBands, canShowBands }`.
- **`setContestBands(input: { show })`**: adults only. Under 18, it is the user error "Comparisons stay off until you are
  18."
- **Platform admins:**
  - **`adminContests`** lists every contest, drafts included.
  - **`saveContest(input: ContestInput)`** creates a draft, or changes one when `id` is given. The input is:
    - `title`, an optional `subjectId`, `opensAt` and `closesAt` (at most seven days apart);
    - `minutes` (5–60) and `questionCount` (3–30);
    - `questions`, each with a `prompt`, 2–6 `choices`, `correct` (an index) and an `explanation`. There are at most 200
      questions.
  - **`publishContest(input: { id })`** needs at least `questionCount` questions and a window not yet closed.
  - **`deleteContest(input: { id })`** deletes drafts only.
  - Anyone else gets FORBIDDEN: "Only platform admins write contests."

## Data

- **Contest tables:** `core.Contest`, `ContestQuestion`, `ContestAttempt` (unique per contest and person) and
  `ContestAnswer`.
- **New column:** `LearnerSettings.contestBands`.
- **Migrations:** `20261103090000_contests` and `20261104090000_mock_interviews`.
- **Export:** `data/core/contest-attempts.json`. Erasure removes a person's attempts.
- **Mock interviews (ADR-0083):** these tables exist with no API: `MockInterviewTemplate`, `MockInterviewQuestion`,
  `InterviewRubricCriterion`, `InterviewSlot`, `MockInterview` and `InterviewFeedback`. Nothing reads or writes them.
