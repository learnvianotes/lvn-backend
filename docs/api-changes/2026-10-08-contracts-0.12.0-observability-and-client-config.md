# @lvn/contracts 0.12.0 — observability and the clients' Phase 1 configuration

- Date: 2026-10-08
- Package: `@lvn/contracts` 0.11.0 → 0.12.0 (unpublished; pre-1.0, so a breaking change bumps the minor)
- Spec: §16.1, §16.5; ADR: 0007, 0022
- Breaking: **yes** for web and mobile (`NEXT_PUBLIC_API_URL` and `EXPO_PUBLIC_API_URL` are now required); no for the
  backend (its new variables are optional)

| Area | Change |
| --- | --- |
| `apiConfigSchema`, `workerConfigSchema` | Adds optional `RELEASE`, `OTEL_EXPORTER_OTLP_ENDPOINT` and `SENTRY_DSN` (http(s) URLs only). |
| `webConfigSchema` | Catches up with lvn-web: required `NEXT_PUBLIC_API_URL`; optional `NEXT_PUBLIC_FEEDBACK_URL` (empty allowed), the Firebase web config, GitHub and LinkedIn client ids and consent pages, and `NEXT_PUBLIC_SENTRY_DSN`. |
| `mobileConfigSchema` | Catches up with lvn-mobile: required `EXPO_PUBLIC_API_URL`; optional `EXPO_PUBLIC_GITHUB_CLIENT_ID`, `EXPO_PUBLIC_GITHUB_AUTHORIZE_URL` and `EXPO_PUBLIC_SENTRY_DSN`. |

## Migration

Backend: nothing required; set the observability variables per environment (docs/architecture/env.md). Web and mobile
already set the API URL in their `.env` / `env/<variant>.env`; their local schemas (`lib/env.ts`, `lib/parse-env.ts`)
mirror this one until the package is published.
