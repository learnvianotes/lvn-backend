# @lvn/contracts 0.14.0 — mail through Amazon SES, and the app's Google sign-in settings

- Date: 2026-10-08
- Package: `@lvn/contracts` 0.13.0 → 0.14.0 (unpublished)
- ADR: 0035, 0007
- Breaking: no

| Area | Change |
| --- | --- |
| `apiConfigSchema`, `workerConfigSchema` | `MAIL_TRANSPORT` accepts `ses`, which needs the new optional `SES_REGION`. SES is called with the process's AWS credentials (the ECS task role), so there is no key to configure. |
| `mobileConfigSchema` | Adds optional `EXPO_PUBLIC_FIREBASE_API_KEY`, `…_AUTH_DOMAIN`, `…_PROJECT_ID`, `…_APP_ID`, `EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID` and `EXPO_PUBLIC_GOOGLE_IOS_CLIENT_ID` for native Google sign-in (ADR-0007). |

## Migration

None; existing `smtp` and `resend` settings are unchanged.
