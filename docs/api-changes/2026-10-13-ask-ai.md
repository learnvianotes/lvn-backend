# Ask AI (P5c)

- Date: 2026-10-13
- Package: `@lvn/contracts` 0.35.0
- Spec: §10.2, §11; ADR-0015, ADR-0042, ADR-0057, ADR-0060
- Breaking: no

## What changes for clients

- **`askAi(input: { question, scope, noteId? })`** returns `{ answer, userErrors }`.
  - `scope` is an `AskAiScope`:
    - THIS_NOTE (with `noteId`): the note as the asker reads it, its draft for its owner and editors.
    - MY_NOTES: the asker's published notes.
    - MY_PLACES: notes shared with their groups and classes.
    - PUBLIC.
    - WORKSPACE comes only from `askAiAboutDoubt`.
  - `question`: 3 to 1,000 characters.
  - Payload errors:
    - VALIDATION: the question, or the WORKSPACE scope;
    - NOT_FOUND: a note the asker cannot read;
    - RATE_LIMITED: the day's allowance;
    - UNAVAILABLE: AI off or failing.
- **`askAiAboutDoubt(doubtId)`** returns `{ answer, userErrors }`. It asks with the doubt and its answers, over the notes
  shared with the workspace. NOT_FOUND when the asker is not on the workspace's team or its mentor.
- **`aiAnswer(id)`** returns an `AiAnswer` or null:
  - `status`: QUEUED, RUNNING, READY or FAILED.
  - `text`: Markdown citing sources as `[n]`. It grows while RUNNING.
  - `sources`: `[AiSource { n, noteId, title, versionId, cardIds, snippet }]`. `versionId` is null for a draft.
  - `error` (FAILED), `question`, `scope`, `noteId`, `doubtId`, `createdAt`.
- **`myAiAnswers(first = 20, noteId?, doubtId?)`**: the asker's answers, newest first.
- **`deleteAiAnswer(id)`** returns `OkPayload`.
- **Live:** `LiveEventKind` gains `AI_ANSWER`. Each time an answer of the viewer's grows or ends, their sockets get
  `{ kind: AI_ANSWER, id }`; refetch `aiAnswer(id)`. Poll every couple of seconds as well while RUNNING, in case the
  socket is down.
- **Data export:** gains `data/ai/answers.json`.

## Authorization

- Everything needs a signed-in asker. Answers are visible only to the person who asked. An answer about one note is
  visible only while they can still read it.
- Every source is a note the asker could read when they asked. The read rule is applied in Postgres before the vector
  search, and again over the notes found.

## What clients should do

- Offer "Ask AI" when `aiStatus.available`:
  - on a note (THIS_NOTE);
  - on an Ask AI page with a scope picker (MY_NOTES, MY_PLACES, PUBLIC);
  - on a workspace doubt (`askAiAboutDoubt`).
- Render `text` as Markdown. Make each `[n]` link to source `n`, and show sources as cards that open the note (and its
  first card).
- Tell people that "My notes" covers published notes only.
