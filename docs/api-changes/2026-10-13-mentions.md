# Mentions (P3p)

- Date: 2026-10-13
- Package: `@lvn/contracts` 0.29.0
- Spec: §4.5; ADR-0047, ADR-0054
- Breaking: no

## What changes for clients

- `NotificationCategory` gains `MENTION`: someone named the viewer with `@handle` in a comment, a group post or an
  idea they can read. `actor` is the writer, `path` the place (`/notes/<id>`, `/groups/<id>`, `/classes/<id>`),
  `data { entityType: COMMENT | GROUP_POST }`.
- `notificationSettings.categories` lists MENTION (push on by default, no email).
- Nothing in comments' or posts' input changes: the API reads `@handle` from the text.

## What clients should do

- Describe MENTION notifications ("<name> mentioned you in a comment" / "in a post"), and label the setting.
- Show `@handle` in comments and posts as a link to `/u/<handle>`; say in the composer that `@handle` mentions
  someone.
