# @lvn/contracts 0.9.0 — no URLs in contracts

- Date: 2026-10-08
- Package: `@lvn/contracts` 0.8.0 → 0.9.0 (unpublished; pre-1.0, so a breaking change bumps the minor)
- ADR: 0022
- Breaking: **yes**

| Area | Change |
| --- | --- |
| `webConfigSchema` | `NEXT_PUBLIC_SITE_URL` is required, with no default. |
| `@lvn/contracts/notifications` | `pushData.deepLink` (full URL or app-scheme link, domain written in the schema) is replaced by `pushData.path`, an in-app path such as `/n/<slug>-<id>`. Full URLs, `//host` and scheme links are rejected. |

## Migration

Set `NEXT_PUBLIC_SITE_URL` in every environment. Push senders put the in-app path in `data.path`; apps join it to their
own scheme or web origin from their environment.
