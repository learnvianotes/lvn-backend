# @lvn/contracts 0.7.0 — verified accounts, data export, notes import

- Date: 2026-10-08
- Package: `@lvn/contracts` 0.6.0 → 0.7.0 (unpublished; pre-1.0, so a breaking change bumps the minor)
- ADRs: 0017, 0018
- Breaking: **yes**

## What changed

| Area | Change |
| --- | --- |
| `Actor` | `emailVerified` is replaced by `institutionVerified` (college or organisation email confirmed). |
| `can()` | One gate, `NEEDS_VERIFIED_ACCOUNT`, for every action that reaches other people (publish, change visibility, share, comment, post, follow, connect, create/join groups, classrooms and workspaces, mentor invites, doubts). Classroom join requests and `NOTE_SHARE` are now gated too; the per-action email checks are gone. |
| `Action` | `ACCOUNT_EXPORT_DATA`, `ACCOUNT_IMPORT_NOTES` (any signed-in user, verified or not). |
| Enums | `FilePurpose.EXPORT`; `BoundedContext`. |
| Events | `InstitutionVerified`, `DataExportRequested`, `DataExportPartReady`, `DataExportReady`, `NotesImportCompleted`. |
| GraphQL skeleton | `SignUpInput.institutionalEmail`; `completeRegistration`, `verifyInstitutionalEmail`, `resendInstitutionalEmailCode`; `User.institutionalEmail`, `institution`, `registrationComplete`; `requestDataExport`, `importNotes`, `myDataExports`, `myNotesImports`. |

## Migration

Callers build `Actor` with `institutionVerified` instead of `emailVerified`. No consumers yet.
