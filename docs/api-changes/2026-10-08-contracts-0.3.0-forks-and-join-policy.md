# @lvn/contracts 0.3.0 — fork publishing and group join policy

- Date: 2026-10-08
- Package: `@lvn/contracts` 0.2.0 → 0.3.0 (unpublished)
- ADRs: 0010, 0011
- Breaking: no — new fields are optional and the new action is additive

## What changed

| Area | Change |
| --- | --- |
| `NoteFacts` | Optional `fork: { originVisibilityAtFork, forkedAsOwnerOrEditor }`. Publishing or changing a fork to PUBLIC is refused unless the origin was PUBLIC when forked or the forker was its Owner/Editor. Publishing without a target visibility now checks the note's current visibility (so a restricted minor cannot republish a PUBLIC note). |
| `Action` | Added `GROUP_JOIN` (direct join of a PUBLIC group whose policy is OPEN). |
| `Resource` (`group`) | Optional `privacy` and `joinPolicy`. `GROUP_REQUEST_JOIN` is refused when the group is OPEN to direct joining. |
| Enums | `GroupPrivacy` (`PUBLIC`, `PRIVATE`), `GroupJoinPolicy` (`OPEN`, `APPROVAL`). |
| Events | `NotePublished` v1 gains optional `forkedFromNoteId`. |
| GraphQL skeleton | `NoteAttribution` gains `ownerHandle` and `originAvailable`. |

## Authorization

Direct join: verified non-member, group PUBLIC and OPEN. Join policy changes: group Admin/Owner via `GROUP_MANAGE`.

## Migration

None needed. The backend passes `fork`, `privacy` and `joinPolicy` once those columns exist (Phase 2 / Phase 3).
