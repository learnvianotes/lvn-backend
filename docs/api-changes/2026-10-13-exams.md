# Exams, weak topics and Exam Readiness (P6e)

- Date: 2026-10-13
- Package: `@lvn/contracts` 0.44.0
- Spec: §14.2; ADR-0030, ADR-0070
- Breaking: no

## What changes for clients

- **`exams: [Exam!]!`** and **`exam(id)`** (signed in) give the viewer's exams from a week ago on, soonest first:
  - `name`, `date` (a learning day, YYYY-MM-DD), `daysLeft`, `past`;
  - `topics`: `key` (`topic:<id>`), `title`, `topic` (the notes `Topic`, null once the viewer may not use it),
    `recall` and `accuracy` (0–1, null without data) and `mastery`;
  - `tasks`: the revision plan, oldest day first: `day`, `topics` (`key`, `title`), `done`, `today`;
  - `readiness` (0–100), `target` (80) and `targetToday`, where the target line is today.
- **`createExam(input: { name, date, topicIds })`**, **`updateExam(input: { id, name?, date?, topicIds? })`** and
  **`deleteExam(input: { id })`**:
  - a name of 1–100 characters; a date today or later, at most two years away; 1–20 topics the viewer may use;
  - at most 10 upcoming exams; other inputs answer `VALIDATION`, another person's exam `NOT_FOUND`;
  - a new date or new topics plan the days from today again.
- **`examTopicOptions(query)`** finds topics to set an exam on, by the words of their titles: `id`, `key`, `title`,
  `subjectTitle`.
- **`weakTopics`** lists weak topics with `reason`:
  - `LOW_ACCURACY`: under 60 % right over the topic's last 3 quiz results;
  - `NOT_REVISITED`: a topic of an exam in the next 14 days with no time on it in the last 14.

  Each has `key`, `title` (null for a /core topic), `topic`, `accuracy`, and the soonest exam it belongs to
  (`examId`, `examName`, `daysLeft`).
- **Rhythm:**
  - `RhythmItem` gains `title` and `topicKey`, and two kinds: `PLAN_TASK` (today's exam-plan tasks, done of all) and
    `WEAK_TOPIC` (one weak topic, done at 10 minutes on it today);
  - `Rhythm.suggestion` (`plannedDays`, `examId`, `examName`, `daysLeft`) suggests one more planned day a week from
    21 days before an exam. Nothing changes until the learner sets it.
- **Learning events:**
  - a `QUIZ_COMPLETED` with `topicKeys` and `metadata: { answered, correct }` is kept as a quiz result on each topic;
  - class quizzes now carry their source note's topics, and flashcard reviews their note's topics.
- **Notifications:** `REVISION_REMINDER` can now be turned off. From 18:00 in the person's zone, an exam task left
  today sends one, opening `/exams/<id>`, with `data: { examName, topics }`.
- The data export gains `learning/exams.json`.

## Authorization

- Each person sees and changes only their own exams, weak topics and results; signed out answers `UNAUTHENTICATED`.
- Topics go through the notes subgraph's rules (curated, or the viewer's own proposal) when set and when read.

## What clients should do

- When a quiz card in a note is checked, send `QUIZ_COMPLETED` with `entityType: NOTE_CARD`, the card id, the note's
  topic keys and `{ answered: 1, correct: 0 | 1 }`.
- Show Readiness against `targetToday`; never frame a task left as a loss.
- Show `REVISION_REMINDER` notifications with the exam's name.
