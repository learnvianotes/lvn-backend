# @lvn/contracts 0.11.0 — Phase 1 backend configuration

- Date: 2026-10-08
- Package: `@lvn/contracts` 0.10.0 → 0.11.0 (unpublished; pre-1.0, so a breaking change bumps the minor)
- ADR: 0022, 0032, 0007
- Breaking: **yes** (backend processes only; `webConfigSchema` and `mobileConfigSchema` are unchanged)

| Area | Change |
| --- | --- |
| `apiConfigSchema` | Adds required `S3_REGION`, `S3_BUCKET`, `S3_RESTRICTED_BUCKET`, `MAIL_FROM`, `MAIL_TRANSPORT`, `JWT_PRIVATE_KEY`, `JWT_PUBLIC_KEY`, `JWT_ISSUER`, `WEB_URL`, `CODE_HMAC_SECRET`; optional `S3_ENDPOINT`, S3 credentials, `S3_FORCE_PATH_STYLE`, `SMTP_URL` / `RESEND_API_KEY` (required by the chosen transport), `DIGITAL_CONSENT_AGE` (default 18), `PASSWORD_BREACH_API_URL`, `FIREBASE_PROJECT_ID`, GitHub and LinkedIn OAuth credentials. PEM keys accept `\n` escapes. |
| `workerConfigSchema` | Adds the same storage and mail variables. |

## Migration

Copy the new lines from `.env.example`; run `pnpm keys:dev` for local keys. Sandbox and production read the secrets
from AWS Secrets Manager (§7.2).
