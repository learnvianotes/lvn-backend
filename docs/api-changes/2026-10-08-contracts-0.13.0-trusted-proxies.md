# @lvn/contracts 0.13.0 — trusted proxies for the client address

- Date: 2026-10-08
- Package: `@lvn/contracts` 0.12.0 → 0.13.0 (unpublished)
- Spec: §7.1, §16.2, §17.1
- Breaking: no

| Area | Change |
| --- | --- |
| `apiConfigSchema` | Adds optional `TRUST_PROXY_HOPS` (0–5, default 0): how many proxies in front of the API are trusted for `X-Forwarded-For`. The client address it yields feeds the new per-network limit on failed sign-ins (credential stuffing, §17.1). |

## Migration

Nothing locally. Sandbox and production set `TRUST_PROXY_HOPS=1` behind the ALB alone, `2` behind CloudFront + ALB —
never more than the real number, or clients could choose their own address.
