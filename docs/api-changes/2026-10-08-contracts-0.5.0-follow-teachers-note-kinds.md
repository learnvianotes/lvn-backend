# @lvn/contracts 0.5.0 — students follow teachers; note kinds

- Date: 2026-10-08
- Package: `@lvn/contracts` 0.4.0 → 0.5.0 (unpublished)
- ADR: 0014
- Breaking: no — `Resource` gains a member (`newNote`); exhaustive `switch`es over it need a new case

## What changed

| Area | Change |
| --- | --- |
| `can()` | `USER_FOLLOW` allows any signed-in user towards a teacher (was teacher-to-teacher). Connect is unchanged. |
| `Action` | `USER_VIEW_FOLLOWERS` (the teacher themself only), `NOTE_CREATE` (checked against the kind). |
| `Resource` | New `newNote` kind with `noteKind`. |
| Enums | `NoteKind` (`NOTE`, `BLOG`, `POST`, `PROJECT`). |
| Events | `NotePublished` v1 gains optional `kind` (absent = `NOTE`). |
| GraphQL skeleton | `enum NoteKind`, `Note.kind`, `CreateNoteInput.kind` (default `NOTE`). |

## Migration

None.
