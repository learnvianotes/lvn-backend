# @lvn/contracts 0.8.0 — verification requests, teachers follow students, push payloads

- Date: 2026-10-08
- Package: `@lvn/contracts` 0.7.0 → 0.8.0 (unpublished)
- ADRs: 0019, 0020, 0021
- Breaking: no — `Resource` gains a member (`verification`), so exhaustive `switch`es over it need a new case

## What changed

| Area | Change |
| --- | --- |
| `Action` | `ACCOUNT_REQUEST_VERIFICATION`, `ACCOUNT_REVIEW_VERIFICATION` (the latter in `NEEDS_VERIFIED_ACCOUNT`). |
| `Resource` | New `verification` kind: `method` (`TEACHER` or `DOCUMENTS`), `pendingRequest`, `targetIsVerifiedTeacher`, `addressedToActor`. |
| `can()` | Teachers (and anyone verified) follow students, never restricted minors. Restricted minors cannot request document verification. Teachers never review document requests. |
| Enums | `VerificationMethod`; `FilePurpose.VERIFICATION_DOCUMENT`; `FileParentType.VERIFICATION_REQUEST`. |
| Events | `VerificationRequested`, `VerificationDecided`; `InstitutionVerified` gains optional `method`. |
| New subpath | `@lvn/contracts/notifications`: `NotificationCategory`, strict `pushData` and `pushMessage` schemas (ids only). |
| GraphQL skeleton | `institutionalEmail` optional at sign-up; verification request/review mutations and queries; `User.verified`, `verificationMethod`. |

## Migration

None.
