# Sharing, quizzes, pages and voice notes

- Date: 2026-11-02
- Package: `@lvn/contracts` 0.74.0 → **0.75.0**
- Breaking: additive. `Visibility` gains `UNLISTED`. `FilePurpose` gains `PAGE_IMAGE`. New fields and operations are optional to query.

## Why

Private was the only visibility clients could select. Transcription sent every recording through the chat API, and Whisper was classified as unable to hear, so the Transcribe picker hid the models that can hear and the call fell through to a chat model.

`unverified_gated_actions` (contracts 0.74.0) still gates `note.publish` and `note.share`. Those do not block a visibility change. An unverified owner can set Private, Shared and Unlisted. Public follows `public_notes_require_verification` (default on) through `Actor.mayPublishPublic`. A verification gate that sets that flag wins over the setting. Listing `note.changeVisibility` on the unverified list blocks every target, including Private.

## Notes

```graphql
enum Visibility { PRIVATE SHARED UNLISTED PUBLIC }

type VisibilityChoice { visibility: Visibility! enabled: Boolean! reason: String }

extend type Note {
  forkCount: Int!
  visibilityChoices: [VisibilityChoice!]
  sharePath: String
  pages: [NotePage!]!
}
```

- `visibilityChoices` and `sharePath` are owner-only. `sharePath` is `/n/{slug}-{id}` when the note is published and Unlisted or Public.
- Unlisted is readable by id (including signed out) and is left out of `publicNotes`, search, profiles and feeds.
- `forkNote` makes a private copy, keeps `forkedFrom`, copies pages, and increments `forkCount`. `setNoteForking` still turns copies off. The owner can still fork their own note.
- `changeNoteVisibility` is the existing mutation. Unlisted and Public need a published version. Public follows the admin setting.

## Pages and uploads

```graphql
enum FilePurpose { ... PAGE_IMAGE }
enum StrokeTool { PEN MARKER ERASER RULER }
type NotePage { id: UUID! index: Int! drawing: JSON! strokes: [InkStroke!]! images: [NotePageImage!]! }
type NotePageImage { id: UUID! fileId: UUID! x: Float! y: Float! width: Float! height: Float! rotation: Float! url: String urlExpiresAt: DateTime }
```

Mutations: `saveNotePage`, `deleteNotePage`, `placePageImage`, `updatePageImage`, `removePageImage`.

`drawing` is `{ strokes: [{ id, tool, color, width, points: [{x,y}] }] }` with `tool` of `pen`, `marker`, `eraser` or `ruler`. Pen and marker need `#RRGGBB`. A ruler is exactly two points. An eraser has no colour.

`PAGE_IMAGE` is PNG or JPEG, `parentId` is the note, and it finishes with `completeUpload` (a remote scan still runs, and `STORAGE_BYTES` still applies). `url` is null while the scan is pending or failed. `VOICE_NOTE` is audio; pass `parentId` to attach it to a note, or omit it for a recording that stands alone.

## Quizzes (core)

```graphql
enum QuizVisibility { PRIVATE UNLISTED PUBLIC }
type SharedQuiz { id title visibility owner publishedAt questionCount questions sharePath visibilityChoices myAttempts stats viewerIsOwner }
```

Queries: `sharedQuiz(id)`, `sharedQuizByLink(token)`, `myQuizzes(first)`, `publicQuizzes(first)`.

Mutations: `createSharedQuiz`, `updateSharedQuiz`, `setSharedQuizVisibility`, `submitSharedQuizAttempt`, `deleteSharedQuiz`.

`sharePath` is `/q/{linkToken}` for the owner when the quiz is not Private. A private token does not open the quiz for anyone else. Unlisted is readable by id and by token and is not in `publicQuizzes`. `myAttempts` is only the caller's. `stats` is owner-only and has no user ids. The first attempt of each person is the score. Questions cannot change once any attempt exists. Public uses the same admin setting as notes.

## Voice (ai)

```graphql
type VoiceCapture { api: String! interimResults: Boolean! continuous: Boolean! languages: [String!]! streamingFallback: String! }
type Transcript { text: String! cut: Boolean! }
type NotesFromTranscript { noteId: UUID! title: String! summary: String! }
```

- `voiceCapture` describes browser `SpeechRecognition` (`en-US`, `en-IN`, `hi-IN`, `te-IN`) and names `transcribeCaptionClip` as the fallback.
- `transcribeAudio(fileId)` transcribes a finished `VOICE_NOTE` or audio `ATTACHMENT`.
- `transcribeCaptionClip(input: { audioBase64, mimeType })` takes at most about 15 seconds and 2.5 MB. It is not stored, so it is not scanned.
- `makeNotesFromTranscript(transcript)` writes a private note (summary, then heading and text sections). At most 20,000 characters are read.

Whisper and `*-transcribe` are on the Transcribe picker and are sent to `POST /audio/transcriptions`. `gpt-audio`, Gemini and Gemma stay on the chat call. See `docs/voice-captions.md`.
