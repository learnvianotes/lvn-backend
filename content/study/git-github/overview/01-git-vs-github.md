The critical distinction between the local tool and the cloud hosting service.

> [!INFO] Git (The Tool)
>
> <strong>Git</strong> is a free, open-source, fast, and scalable distributed version control system that runs locally on your computer's command terminal. It creates and tracks local history logs.

> [!INFO] GitHub (The Platform)
>
> <strong>GitHub</strong> is a commercial, web-based hosting platform that stores your Git repositories in the cloud. It provides features like Pull Requests, issue tracking, user access management, and visual collaboration tools.

# Key Distinctions

| Dimension | Git | GitHub |
| --- | --- | --- |
| <strong>Nature</strong> | Local CLI software program | Cloud hosted web platform (SaaS) |
| <strong>Installation</strong> | Required on developer's local machine | No installation (accessed via browser) |
| <strong>Network</strong> | Runs entirely offline | Requires internet connection to sync/push |
| <strong>Key Competitors</strong> | Mercurial, SVN, Perforce | GitLab, Bitbucket, AWS CodeCommit |

> [!TIP] Real-world Analogy
>
> Think of <strong>Git</strong> as the camera on your phone that takes pictures (commits) and stores them in your local gallery. Think of <strong>GitHub</strong> as Instagram — a public/private web platform where you upload (push) those pictures to share and collaborate with others.
